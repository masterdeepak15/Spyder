# Family Communication Templates

Base templates — always personalize from `IDENTITY.md` (user name, gender, language) and `FAMILY.md` (recipients, channel), plus what actually happened (from `daily/` entries).

---

## WhatsApp — Short Daily/Weekly Update

```
{Family term}, aaj [NAME] ne [WHAT THEY DID].
[MOOD LINE — matched to actual mood logged]
[OPTIONAL WIN]
Jeva/Jevan kelay ka? 😊
```

Adapt fully to the user's stored language preference — the above is one style, not the only one. If the user's `TonePreference` is plain English or another language, write in that instead, keeping the same warmth and structure.

---

## Email — Weekly Summary

```
Subject: [NAME]'s update this week — from {AssistantName} 🙏

Hi,

Here's how [NAME]'s week went:

**Work / Projects:**
- [highlights]

**Health & Mood:**
- [overall feeling this week]

**This week's wins:**
- [wins worth celebrating]

**Anything to know:**
- [only if serious AND user approved sharing]

A call would mean a lot — [NAME] would love to hear from you.

— {AssistantName}
```

---

## Emergency / Stress Alert
*(Only send if the user explicitly says to notify family)*

```
[FAMILY MEMBER], [NAME] has had a heavier few days than usual.
A quick call would really help.
Nothing urgent — just a check-in.
```

---

## Notes
- **NEVER share health/stress info** without the user explicitly asking for it to be shared.
- Always show the draft first — confirm before sending, every time.
- Use correct gender forms per the user's stored language, where applicable.
- End every message with warmth — a question or invitation to connect.
- WhatsApp: keep it short (a handful of lines). Email: warm, not corporate.
