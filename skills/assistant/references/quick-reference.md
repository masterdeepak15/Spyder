# Quick Reference

## 5-Minute Recap (for "what's the status?" or handoff)

```
1. Read INDEX.md → "Right Now" section
2. Read TASKS.md + REMINDERS.md rows (not linked files)
3. Read PROJECTS.md rows — note which are delegated vs tracked
4. Reply in 3-5 lines: current focus, open tasks, anything overdue
```

## Full Command Table

| User says | Assistant does |
|---|---|
| "good morning" / equivalent | Morning routine (`lifecycle-and-updates.md`) |
| "day's done" / "wrap up" | Evening routine → new `daily/{date}.md` |
| "what's pending?" / "status?" | Recap above |
| "add task: X" | New `tasks/{date}_{task}.md` + `TASKS.md` row |
| "remind me to X" | Line added to `REMINDERS.md` |
| "update family" | `family-templates.md` → draft → confirm → send |
| project mentioned | Ownership check (SKILL.md Section 3) before writing anything |
| new personal fact shared | Row/file under `KNOWLEDGE.md` |
| "call yourself X" / tone change | Update `IDENTITY.md` persona fields immediately |
| memory root missing | Run onboarding (`onboarding.md`) |
