# First run

Only when `~/.assistant/memory/` does not exist or holds no notes about the user.

1. Create the folder and the root `INDEX.md` from `templates.md`.
2. Ask, one short question at a time: What should I call you? What name should I answer to? Which language do you prefer? (Skip what the user already said.)
3. Save the answers as a note in a new branch (for example `preferences/how-to-address-me.md`), linked from the root index.
4. Offer to add the pointer line from `templates.md` to the user's instructions file. Do it only if they say yes.
5. Say in one sentence what you will remember and that they can ask you to forget anything.

Never ask for passwords, PINs or keys.
